## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/MasQuantumCoder-34/masood_portfolio_nextjs.git
cd masood_portfolio_nextjs

# 2. Configure environment
cp .env.example .env.local

# 3. Install dependencies
pnpm install

# 4. Start local development server
pnpm run dev
```

Visit `http://localhost:3000` in your browser.

## 🛠️ Tech Stack

- **Core:** Next.js 16 (App Router), React 19, TypeScript 5
- **Styling:** Tailwind CSS v4, OKLCH colors, `tw-animate-css`
- **UI System:** Radix UI primitives, shadcn/ui (New York style), Lucide React
- **Database:** Firebase Realtime Database v12 (Live Testimonials)
- **Forms & Email:** Formspree API
- **Analytics:** Vercel Web Analytics
